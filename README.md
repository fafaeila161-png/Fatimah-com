# Savoria - Platform Jual Beli Makanan

Savoria adalah website modern, responsif, dan elegan yang dirancang khusus untuk platform jual beli makanan / kuliner. Website ini sangat cocok digunakan sebagai portofolio atau demo produk untuk memikat klien.

---

## 🚀 Fitur Utama
1. **Desain Modern & Menggoda:** Tampilan visual tingkat tinggi yang meningkatkan minat beli konsumen.
2. **Sistem Keranjang Interaktif:** Fitur tambah/hapus pesanan real-time serta simulasi checkout.
3. **Filter Kategori Dynamic:** Memudahkan navigasi menu berdasarkan jenis makanan/minuman.
4. **100% Responsif:** Tampil sempurna di perangkat mobile, tablet, maupun desktop.
5. **Siap GitHub Pages:** Tanpa perlu setup server/backend khusus.

---

## 🛠️ Cara Deploy ke GitHub Pages (Gratis & Mudah)

1. **Ekstrak File ZIP** ini di komputer Anda.
2. Buat **Repository Baru** di [GitHub](https://github.com/):
   - Beri nama repository (contoh: `savoria-food`).
   - Atur menjadi **Public**.
   - Klik **Create Repository**.
3. **Upload File**:
   - Unggah ketiga file (`index.html`, `style.css`, dan `script.js`) langsung ke repository tersebut.
   - Klik **Commit Changes**.
4. **Aktifkan GitHub Pages**:
   - Buka tab **Settings** di repository Anda.
   - Pada sidebar kiri, pilih **Pages**.
   - Di bagian *Branch*, pilih **main** (atau **master**), lalu klik **Save**.
5. **Selesai!** Dalam 1–2 menit, link website publik Anda akan muncul di bagian atas halaman GitHub Pages!
